# Palate Release Notes: v1.5.22

**Release Date:** September 4, 2026  
**Target Version:** `1.5.22`

---

## Highlights

Palate v1.5.22 delivers a comprehensive architectural refactor and hardening of the **Sage AI Backend**, transitioning to native tool calling with concurrent tool execution, upgrading Gemini 3.8 Flash model reasoning parameters, enforcing strict Zod 4 input schemas, and guaranteeing stream and Markdown table integrity.

---

## 1. Native Tool Calling & Concurrent Orchestration (`src/lib/sage.ts`)
- **Owned Concurrency Orchestration**: Replaced legacy sequential tool loops with an owned orchestration layer utilizing `Promise.allSettled`, dispatching parallel function calls concurrently during multi-tool model turns.
- **Strict Positional Ordering & Isolation**: Preserves exact positional order of incoming `FunctionCall` objects and their unique `id`s, while isolating errors per call so individual tool rejections do not abort sibling operations.
- **Immediate Streaming & EOF Flush**: Emits tool execution UI tokens immediately upon valid schema validation and buffers stream tokens through an `AsyncQueue` to prevent stream stalls.
- **Thought Demarcation State Machine**: Implemented `ThoughtDemarcator` to assemble reasoning fragments into single contiguous `<thought>...</thought>` blocks and close open thought blocks before any tool UI tokens are emitted.

---

## 2. Gemini 3.8 Flash Configuration Hardening
- **Thinking Level Alignment**: Upgraded `SAGE_JSON_THINKING_CONFIG` from `ThinkingLevel.MINIMAL` (unsupported by Gemini 3.8 Flash) to `ThinkingLevel.LOW` (`src/lib/ai/model-config.ts`).
- **Purged Deprecated Parameters**: Removed deprecated `temperature` sampling overrides across all 5 Gemini 3.8 Flash entry points (`src/lib/sage.ts`, `wellness/route.ts`, `zero-waste/route.ts`, `suggest-name/route.ts`, `calendarAgent.ts`, `sage-food-discovery.ts`).

---

## 3. Zod 4 Schema Validation & Table Integrity
- **Zod 4 Number Schemas**: Implemented `createPositiveNumberSchema` and `createNonNegativeNumberSchema` with Zod 4 type compatibility, strictly rejecting non-numeric strings, negative values, zeros (for positive fields), NaNs, and infinities.
- **Path-Aware Error Reporting**: Formatted schema errors via `formatZodError` to prepend field names, enabling Gemini to correct invalid arguments accurately.
- **USDA Markdown Table Restored**: Restored the missing 9-column delimiter row in the USDA macros table template, ensuring pristine Markdown rendering.

---

## 4. Test Coverage & Release Agreement
- **32-Test AFC Unit Suite**: Added `tests/unit/sageAfc.test.ts` testing tool concurrency timing, positional order preservation, error containment, Zod 4 validation, thought demarcation, and UI token precedence.
- **Full Vitest Suite**: 53 test files, 357 tests passing cleanly across the entire Palate codebase.
- **Static Types & Linting**: 0 TypeScript errors (`tsc --noEmit`) and 0 ESLint errors.
- **Version Agreement**: Synchronized release version across `package.json`, `package-lock.json`, `src/lib/version.ts`, Jellyfin client headers (`JELLYFIN_CLIENT_HEADER`), and release notes documentation.
