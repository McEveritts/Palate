# Palate Release Notes: v1.5.21

**Release Date:** September 4, 2026  
**Target Version:** `1.5.21`

---

## Highlights

Palate v1.5.21 delivers key UX and ergonomic enhancements to **Sage Fitness**, featuring a scroll-direction aware auto-hiding floating action dock (`MultiAddDock`), refined responsive module spacing, symmetric lateral padding on the daily fitness diary (`diary/page.tsx`), and full unit test coverage.

---

## 1. Scroll-Direction Aware Floating Action Dock (`MultiAddDock.tsx`)
- **Auto-Hide on Scroll Down**: The quick-add floating pill dock automatically translates downwards off-screen (`y: 80, opacity: 0`) and disables pointer interactions when the user scrolls down the page, maximizing reading area for nutrition logs and timeline modules.
- **Immediate Reveal on Scroll Up**: Scrolling back up immediately reveals the dock (`y: 0, opacity: 1`) using smooth Framer Motion spring physics (`stiffness: 350, damping: 30`).
- **Top Sticky Clearance**: The dock remains unconditionally visible when the user is at or near the top of the viewport (`scrollY <= 10px`), ensuring immediate access upon landing.
- **Rubber-Band Rebound Clamping**: Clamps scroll tracking to `[0, maxScroll]` (`scrollHeight - clientHeight`), preventing elastic overscroll snap-back jitter at the bottom of the page from erroneously triggering upward-scroll reveal animations.
- **Universal Root & Container Support**: Accurately tracks scroll events on the primary application shell container (`#palate-main-content`) as well as `document.documentElement` and `document.body` with fallback to `window` scroll coordinates for universal compatibility across desktop and mobile browsers.
- **Nested Scroll Isolation**: Filters out scroll events bubbling from nested inner scroll containers (such as modal lists, search result dropdowns, or drawer sheets) so background scrolling logic is never erroneously triggered.
- **Radial Menu Auto-Dismissal & Mobile Wrap**: Automatically closes the expanded radial quick-add menu upon downward scrolling, ensuring the menu does not reappear unexpectedly when the dock returns. Refactored the radial menu container with `flex-wrap justify-center max-w-[calc(100vw-2rem)]` so quick-add buttons wrap gracefully on narrow mobile screens.
- **Mobile Clearance**: Positioned with `bottom-20 md:bottom-8` to ensure clean clearance above the fixed mobile navigation bar on smaller viewports.

---

## 2. Responsive Sage Fitness Diary Spacing (`diary/page.tsx`)
- **Lateral Gutter Symmetry**: Upgraded the diary root container from a rigid `p-6` to an adaptive responsive padding scale (`px-4 sm:px-6 md:px-8 lg:px-10 py-6 pb-32`), eliminating crowded module edges on mobile and providing comfortable gutters on wide displays.
- **Expanded Container Width**: Broadened the centered content width from `max-w-5xl` to `max-w-7xl mx-auto space-y-8`, optimizing horizontal layout balance and card proportions on modern displays.
- **Grid Column Spacing**: Synchronized grid gaps across top widgets (`MacroGlassCard`, `MicroNutrientCard`, `ContributionGrid`, `FastingTimer`, `HydrationEnergyRow`) with `gap-6 lg:gap-8`, ensuring consistent vertical and horizontal rhythm.
