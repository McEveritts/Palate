# Palate Release Notes: v1.5.12

**Release Date:** September 4, 2026  
**Target Version:** `1.5.12`

---

## Highlights

Palate v1.5.12 delivers **Phase 4: Calendar & Vault Workflows**, introducing container-driven density rules for the Culinary Scheduler, fluid ultrawide layout scaling, CSS Grid architectural refactoring for the Recipe Vault, and comprehensive mobile touch accessibility.

---

## 1. Calendar Density & Container Query Engine
- **Container-Decoupled Density**: Implemented `useContainerWidth` leveraging `ResizeObserver` on the calendar root container (with fallback to client rect dimensions and CSS `@container` queries). Density dynamically responds to sidebar toggles, split panes, and drawer resizing rather than viewport width alone.
- **1-Day Mobile Presentation (`< 500px`)**:
  - Renders a single active day column utilizing the full available container width for comfortable meal reading.
  - Adds a compact 7-pill day selector strip across the top displaying day names, date numbers, active indicators, and dot badges for scheduled meals.
  - Prev/Next navigation steps day-by-day and seamlessly transitions week boundaries.
- **3-Day Tablet Presentation (`500–1047px`)**:
  - Renders 3 columns side-by-side with balanced column widths, preventing layout cramming or horizontal overflow.
  - Prev/Next navigation steps by 3-day increments with a quick "Today" reset.
- **7-Day Desktop Presentation (`≥ 1048px`)**:
  - Full 7-column layout optimized for wide displays with a 1048px compact floor.
  - Prev/Next navigation steps by weekly increments.

## 2. Interactive Scheduling & Rescheduling Workflows
- **In-Modal Meal Rescheduling**: The scheduled meal details modal features a "Reschedule / Move Meal" interface allowing users to adjust meal dates and change meal types (`Breakfast`, `Lunch`, `Dinner`, `Snack`) directly, backed by `moveScheduledMeal`.
- **Dynamic Scheduling Date Initialization**: Opening the "Schedule Meal" modal defaults the date input to the currently active day in 1-day/3-day views.
- **Batch Leftover DAG Visualization & Symbolic Math Scaling**: Meal portions and macronutrient profiles remain fully interactive and scaled across all 3 view modes.

## 3. Fluid Container Expansion & Layout Corrections
- **Fluid Ultrawide Layout**: Removed the rigid `max-w-7xl` constraint from `src/app/calendar/page.tsx`, aligning the Culinary Calendar with the Vault's fluid `max-w-[2400px]` width.
- **Semantic DOM Validation**: Replaced the nested `<main>` element in `src/app/calendar/page.tsx` with a responsive `div` container, resolving duplicate `<main>` landmarks within the root layout shell.

## 4. Vault Grid Refactoring & CSS Grid Architecture
- **CSS Grid Modernization**: Replaced CSS multi-column (`columns-*`) layout in `VaultGrid.tsx` with modern CSS Grid (`grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 3xl:grid-cols-5 4xl:grid-cols-6 gap-6 items-start`).
- **Eliminated Layout Fragmentation**: Prevents column break fragmentation, unpredictable card heights, and scroll jumping when rendering dynamic recipe cards.

## 5. Touch Accessibility & Responsive Hover Enhancements
- **Hover/Touch Macro Dashboard**: Refactored the macro dashboard (`.vault-macro-dashboard`) to be visible by default on mobile devices and touch screens (`@media (hover: none)` and `< 768px`), while preserving smooth hover expand/reveal on desktop pointer devices (`@media (hover: hover)`).
- **Touch-Visible Card Deletion**: Upgraded the glassmorphic card deletion button with `.touch-visible-hover-reveal`, ensuring it is accessible and visible on touch devices without requiring mouse hover, with safety confirmation timers and minimum tap target sizing.

## 6. AI Engine Upgrade: Gemini 3.8 Flash
- **Single Source of Truth**: Upgraded primary culinary reasoning model across all SageAI endpoints (`src/lib/ai/model-config.ts`, curation, nutrition, zero-waste streaming, and calendar assistant) to **Gemini 3.8 Flash** (`gemini-3.8-flash`).
- **Thinking Configuration**: Maintained native thinking profiles with `ThinkingLevel.MEDIUM` for creative culinary planning and `ThinkingLevel.MINIMAL` for deterministic JSON extractions.
- **Settings & Test Verification**: Added comprehensive test coverage asserting API key validation and model parameters across Google GenAI client invocations.
