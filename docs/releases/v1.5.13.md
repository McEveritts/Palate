# Palate Release Notes: v1.5.13

**Release Date:** September 4, 2026  
**Target Version:** `1.5.13`

---

## Highlights

Palate v1.5.13 upgrades SageAI's reasoning depth to **High** (`ThinkingLevel.HIGH`), unlocking deeper cognitive chains, complex multi-recipe synthesis, meticulous culinary chemistry evaluations, and rich thought-trace visibility across conversational endpoints.

---

## 1. High Reasoning Depth Configuration
- **Deep Cognitive Chains**: Configured `SAGE_THINKING_CONFIG` in `src/lib/ai/model-config.ts` to utilize `ThinkingLevel.HIGH` with `includeThoughts: true`.
- **Culinary Chemistry & Multi-Recipe Synergy**: Enables Gemini 3.8 Flash to evaluate multi-step flavor dynamics, pan temperatures, ingredient substitutions, and batch cooking DAG leftovers with maximum analytical rigor.
- **Zero-Waste Streaming**: Real-time zero-waste recipe synthesis produces comprehensive thought traces before streaming MasterChef-grade instructions.
- **Deterministic JSON Isolation**: Preserved `ThinkingLevel.MINIMAL` with `includeThoughts: false` for structured metadata extraction endpoints to prevent JSON payload corruption.

## 2. Test Suite & Mock Agreement
- Added `HIGH` thinking level support to all test mock suites (`tests/api/sage/zero-waste/route.test.ts`, `tests/api/curate.test.ts`, `tests/api/nutrition.test.ts`).
- Updated unit test assertions in `tests/unit/modelConfig.test.ts` ensuring `SAGE_THINKING_CONFIG` strictly enforces `ThinkingLevel.HIGH`.
