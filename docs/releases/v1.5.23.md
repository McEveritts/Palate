# Palate Release Notes: v1.5.23

**Release Date:** September 5, 2026
**Target Version:** `1.5.23`

## Highlights

Palate v1.5.23 repairs Sage transactional logging and aligns Gemini 3.8 Flash reasoning settings with the provider's supported configuration.

## Sage logging reliability

- Replaced unsupported `ThinkingLevel.MINIMAL` with `ThinkingLevel.LOW` for logging turns.
- Expanded intent detection for natural reports such as “I just drank…”, “I just finished lunch…”, and “My weight is…”.
- Added authenticated server-side persistence for food, exercise, hydration, and weight tool calls.
- Returns tool success only after the database operation commits; failed or guest persistence no longer emits a false success marker.
- Preserved a versioned legacy client-persistence path for cached clients during rollout.
- Processes every complete tool marker in a stream buffer, including multiple markers of the same type.
- Added upper bounds matching the public hydration and weight APIs.

## API and data hardening

- Returns HTTP 400 for malformed Sage request JSON.
- Aligns optional tool declarations with their Zod schemas.
- Includes defensive Atwater handling for negative and non-finite nutrient data.
- Uses the browser's local hour when assigning server-persisted food logs to a meal category.

## Verification

- Added unit coverage for transactional persistence, persistence failures, guest-disabled logging, marker coalescing, partial stream markers, and malformed markers.
- Added route coverage proving persistence completes before a success marker is streamed.
- Full verification passed: 384 Vitest tests (24 integration tests skipped by configuration), TypeScript with no errors, ESLint with no errors, and a successful production build.
